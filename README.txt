Neo Dialer - Android 11 (API 30) dialer, minSdk 21, works on Realme C21.
Features: dark iOS-style keypad, recents (call log), contacts, tap to call,
long-press backspace to clear, handles tel: links.

BUILD APK:
1. Install Android Studio, choose File > Open > select this NeoDialer folder.
2. Let Gradle sync (needs internet). If asked, accept the Gradle/AGP upgrade prompt.
3. Build > Build Bundle(s)/APK(s) > Build APK(s).
4. APK: app/build/outputs/apk/debug/app-debug.apk -> copy to phone and install.
